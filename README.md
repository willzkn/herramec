# Herramec E&M EIRL · Catálogo & Sitio Web Industrial

Sitio web oficial y catálogo interactivo de herramientas manuales de alta resistencia térmica y anticorrosiva para minería, fundición y plantas concentradoras del Perú.

## 🚀 Sitio Web en Vivo (GitHub Pages)
👉 **[https://willzkn.github.io/herramec/](https://willzkn.github.io/herramec/)**

---

## 🛠️ Características del Proyecto
- **Arquitectura Multi-página**: 7 páginas independientes (`index.html`, `productos.html`, `servicios.html`, `nosotros.html`, `contacto.html`, `cotizador.html`, `producto-detalle.html`).
- **Diseño Estilo Patagonia Industrial**: Contrastes técnicos limpios, bordes milimétricos, iconografía SVG sin clichés ni emojis, tipografías técnicas `Inter` y `Space Grotesk`.
- **Catálogo Técnico Filtrable**: 29 herramientas industriales clasificadas por ambiente de trabajo (Fundición, Forja Pesada, Antichispa, Muestreo PP, Insumos Térmicos).
- **Módulo de Cotización B2B**: Lista interactiva para compras con guardado local y exportación directa a WhatsApp con formato corporativo.
- **100% Responsive & Dark Mode**: Optimizado para dispositivos móviles en planta y monitores de oficina técnica.
